# business-site

The 2017 version of the **Hanson Software LLC** marketing website. It's a static, responsive site that advertised the company's mobile apps ("4 apps available in 155 countries") and included an **All Apps** page featuring *Trippy Animations*, plus a teaser for the then-upcoming *Pickup Line Generator*.

> The current version of the site is in [HansonSoftwareLLC.com](https://github.com/hanson0291/HansonSoftwareLLC.com). This repo is kept as an archive.

## Pages

| File | Description |
|---|---|
| `index.html` | Landing page with the hero banner, app stats and a call to action |
| `allapps.html` | App catalog |
| `generic.html` | Generic content page from the template |
| `elements.html` | Reference page showing the template's UI elements |

The rest of the repo is static assets: `assets/` (CSS, Sass, JS and fonts), `images/`, and `allapps_files/`.

## Built with

- **[Spectral](https://html5up.net/spectral)** by HTML5 UP ([CC BY 3.0](https://html5up.net/license)). See `README.txt` and `LICENSE.txt`.
- Skel, jQuery, Scrollex and Scrolly, all bundled with the template

## Run locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
